# skidle.github.io

Personal site. Next.js 16 + React 19 + Tailwind 4, statically exported (`output: "export"`)
and served from GitHub Pages at [dariadoronina.com](https://dariadoronina.com).

## Development

```
npm install
npm run dev
```

Then open http://localhost:3000.

## Scripts

| Command | What it does |
| --- | --- |
| `npm run dev` | Start the dev server |
| `npm run build` | Build the static export into `out/` |
| `npm run lint` | Run ESLint |
